# Video Capture & Upload Service

Проект состоит из двух независимых компонентов:

1. **Server (`server/`)** — веб-сервис на Node.js (Express + встроенный `node:sqlite`) для приёма, хранения и раздачи видеофайлов.
2. **Client (`client/`)** — Python-рекордер на базе Playwright для записи сценариев из `input.csv`, загрузки готовых видео на сервер и их автоматического предпросмотра в браузере.

## Требования

- **Node.js** версии **22.5+** или **24+** (используется встроенный модуль `node:sqlite`).
- **Python** версии **3.10+**.

## Установка и настройка

### 1. Настройка сервера (Node.js)

Перейдите в директорию `server` и установите зависимости:

```bash
cd server
npm install
```

### 2. Настройка клиента (Python)

Перейдите в директорию `client`, установите зависимости и браузер Chromium для Playwright:

```bash
cd client
pip install -r requirements.txt
python -m playwright install chromium
```

## Запуск

### Шаг 1. Запуск веб-сервиса

В первом окне терминала запустите сервер из папки `server/`:

```bash
cd server
npm start
```

По умолчанию сервер запускается на `http://0.0.0`. При необходимости можно задать другие параметры через переменные окружения `HOST` и `PORT`.

### Шаг 2. Запуск рекордера

Во втором окне терминала запустите скрипт из папки `client/`:

- **Запись, загрузка на сервер и предпросмотр (5 секунд на каждое видео):**

  ```bash
  cd client
  python capture_video.py --server http://127.0.0.1:8000 --view-seconds 5
  ```

- **Запись, загрузка и ручной режим предпросмотра (окно браузера ждёт нажатия Enter):**

  ```bash
  cd client
  python capture_video.py --server http://127.0.0.1:8000 --view-seconds 0
  ```

- **Автономный режим (только локальная запись без отправки на сервер):**
  ```bash
  cd client
  python capture_video.py
  ```

## API Эндпоинты сервера

| Метод  | Путь                | Описание                                                                                                                                                    |
| :----- | :------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `POST` | `/upload`           | Принимает `multipart/form-data` (`company_name`, `file`), сохраняет видео и обновляет запись в БД (upsert). Возвращает JSON с `company_name` и `video_url`. |
| `GET`  | `/get_video_url`    | Принимает query-параметр `?company_name=<name>`. Возвращает `video_url` или `404`, если компания не найдена.                                                |
| `GET`  | `/media/<filename>` | Раздаёт загруженные видеофайлы для воспроизведения в браузере.                                                                                              |
| `GET`  | `/videos`           | Возвращает список всех записей из базы данных.                                                                                                              |

## Программный интерфейс клиента (`video_client.py`)

Модуль предоставляет две функции для интеграции в сторонние скрипты:

- `UploadVideo(server_url: str, video_path: str, company_name: str) -> str` — загружает файл на сервер и возвращает прямую ссылку на видео.
- `GetVideoURL(server_url: str, company_name: str) -> str` — запрашивает ссылку на видео по названию компании.
